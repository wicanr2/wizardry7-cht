# 022 新增角色清單的性別與職業碼

狀態：READY。2026-10-04；[#22](https://github.com/wicanr2/wizardry7-cht/issues/22)、[#28](https://github.com/wicanr2/wizardry7-cht/issues/28)。R930獨立複審0／0／0，主代理完整回讀後採認。只批准本契約限定顯示層實作，尚未正式驗收。

## 目的與證據

使用者要求完整中文化所有按鈕及訊息，預設畫布已定案3倍，不縮中文字。角色姓名依[names](../names.md)保留原版英文，只覆繪性別與職業。證據見[025的R928](../re/025-ui-localization-coverage.md#r928-角色列的目的區域)。本契約先限定正常新增角色清單的六個已量字串，不推論任意角色record格式、其他列表或選取規則。

resident印字入口0110:3895、返回0110:0fcc、字型0，x150及y150／156／162／168／174／180。六列各15字元，原版逐字座標150、156至234，返回時x240，y保持。前十格包含姓名及空白；後五格為碼，原版碼帶x210..240、y..y+6。未選取的差異為195底色變180前景；選取後為1白底變0黑字。初始六次與首列、末列選取後十二次共十八次全離屏補量，碼帶與已知姓名格外差異0。實際GUI完成新增、兩次選取、取消、正常退出；探針只補量，不取代GUI。

## 擬定實作契約

1. 正式文案新增`text/roster.zh-TW.tsv`，沿既定五欄`en、zh、context、dy、source`。本家族`context`只接受`character.add.roster`、`dy`只接受0、`source`只接受`runtime:0110:0fcc`；source只作出處，不當查找鍵。不讀MSG或改008三個既有catalog的遷移狀態。
2. 六個英文碼為M-FIG、F-FIG、M-THI、M-PRI、M-MAG、F-ALC。文案依既定職業譯名補性別字，候選依序男戰士、女戰士、男盜賊、男牧師、男法師、女鍊金術士。正式譯文只放TSV，產生的JSON只存文案與原生字模，不在Go複製中文文案。六鍵非空、不重複，欄數、UTF-8、字型覆蓋及原生寬度強制檢查。本家族依已量90像素碼欄驗寬，覆蓋一般英文長度二分之一的文案估算；不省略既定職業譯名。
3. 只在scale3、精確resident返回、字型0、x150、既有六個完整英文鍵與其已量y相符時識別碼。名字與padding照原版保留；不把相同碼在其他caller或任意姓名列收為新路徑。每次仍比完整英文及呼叫訊號，後五字元只作已確認子區域，不將前十格視為通用record格式。
4. 在原版印字入口與匹配SP的返回取既有唯讀前／後快照，建立只含碼帶的事件。範圍固定x210..240、y..y+6；拒絕空差異、未知色號、碼帶以外非已知姓名筆畫差異、或其他未證實變化。英文姓名不列入清除範圍。碼帶狀態沿001的原版A000／離屏判斷及游標容忍，事件失效就移除中文，不在遊戲記憶體寫入。
5. 以原生15／16列、每字加2像素間隔在x210×3、y×3畫譯文，整串寬不超90、字高不超18。HD及Draw使用同一字模，不更改原版命中區、輸入、存檔或規則。不得回到英文姓名時留部分中文或殘影。
6. 2倍畫布本輪保持既有英文及可辨認缺譯紀錄。其列距12小於原生字高15／16，欄寬60小於最長83／88。本輪不縮字、改職業譯名、重排姓名或自動切換倍率；2倍完整中文另有排版閘門，不以此宣稱全部倍率完成。既有3倍預設及021兩按鈕修正不改。
7. 資源缺檔、格式錯誤、缺字、未知caller／字型／座標／英文、倍率不符或狀態無法確認時保留原文並記錄。未知分支保持未量，不因單測標CONFORMED。

## 擬定驗收

- 獨立原字型重建兩後端，新增碼文案缺字0；既有譯文及字型檔全部保持。新源只能由TSV生成，不以舊JSON產生器新增內嵌譯文。
- 針對六個精確訊號、反例、未知格式、原版姓名保留及碼帶生命週期測試；不以同一helper輸出作期望值。
- 先以真正GUI重走新增與取消返回、正常退出及持久角色內容保持。再四組字型／倍率固定原輸入與三個停止點做同狀態A/B；3倍只改批准碼帶，2倍HD與Draw保持基準，原版Step／Mem／A000／Pal／Mouse及原始檔逐位元保持。
- 獨立字型與原版筆畫oracle核六列中文、姓名全部像素保持、中文框及筆畫在列表內、列間不重疊、取消後中文消失。完整性對帳分開六列碼及其他80次事件，不宣稱原有未分類英文字樣完成。
- 六列與取消成功不證明任意姓名、捲動、其他職業、選取建立角色、圖片按鈕或完整可玩。需要新正常路線證據才擴大。

### B1 獨立TSV家族

- 由新`tools/re/bake_roster.py`解析`text/roster.zh-TW.tsv`。五欄表頭精確為`en\tzh\tcontext\tdy\tsource`，順序及欄數固定。UTF-8且不帶BOM，CRLF可按行尾讀取；空白列、重複英文鍵、缺欄、未知context、非0的dy及非精確`runtime:0110:0fcc`拒絕。這六列皆無控制碼或placeholder，本家族只收直接字元，不接受反斜線跳脫或欄內控制字元。英文必須恰為六個已量碼的集合，譯文非空、僅含可用原生中文字形，不能混入姓名。008三個舊家族的source語法及DRAFT狀態不變。
- 烘製函式接收既有`bake_font.glyph_char`及字高，沿同後端產生15／16列字模。只在全部TSV、字模及90×18行寬驗證成功後，以exclusive方式建立`<outdir>/roster.json`。`bake_font.bake`加入對此獨立函式的呼叫；既有xlate／flow／help內容保持。獨立CLI允許指定TSV、輸出及既有合法原字型路徑，以便只重建本家族，不必讀舊訊息表。
- 產物為typed JSON：`schema`固定1、`size`為15或16、`context`及`source`為上列閉集合值、`source_sha256`為TSV雜湊，`entries`為六筆陣列。每筆只有`en、zh、dy、g`，g為每個原生中文字的row-word陣列。Go不複製中文文案；en、context及source識別字可以保存在adapter。
- `cmd/wiz7/roster.go`載入選用的`xlate.json`同目錄`roster.json`；純英文模式不載入。以有限檔案大小、未知欄拒絕及單一JSON文件檢查讀取。檢查schema、後端字高、六個不重複英文鍵、dy0、譯文字數與字模數相同、每字高度一致、位元不越字高、非空字形及90像素行寬；缺檔或不合格整份停用並記錄，不留下部分中文資源。size16的每字末列須0，烘製端同樣檢查，對應本輪已量底邊例外；size15不會伸入第六列。既有一般、流文及F1資源型別不變。

### B2 部分事件與完整列身分

- 家族在既有compound／flow仲裁之後、一般查表及無譯文早退之前接入。只在互動與HD配置皆3倍、家族資源有效、near返回0110:0fcc、字型0、x150及已量y時讀最多16 bytes含NUL；不跨16-bit offset界限。完整15字元必須與該y的精確鍵相同，末byte必須NUL。無法確認時保留英文並記錄，不拿未知名字拼碼翻譯。
- 新專用pending保存完整來源、原版x150、目的x210、y、返回、SP、字型、碼鍵與整張離屏before。巢狀時沿001捨棄舊pending並記錄；沒有before不建立。匹配返回IP及SP＝入口SP+2後，專用finish先於一般全圖差異finish執行，不為同列建立一般事件。
- 專用finish比對整張64,000像素離屏。只允許本列已知姓名格`[150,150+6×名字字元數)`及碼帶`[210,240)`、y帶`[y,y+6)`內195→180或1→0的改變，單列只能有其中一對；姓名、碼皆須有實際差異，其他位置或色號改變一律拒絕。全圖補量收據證實此條件，但仍限六個實例。事件的還原before／after只含碼帶；姓名及空白不列入清除。選取色號0是合法前景，不能因為0而丟棄字形。
- 另保存完整列`[150,240)×[y,y+6)`的after為唯讀身分見證。A000及pending離屏狀態判定除了碼帶，還須核此完整列，沿001游標例外。唯一底邊例外是未選取列的第六列：實測下一列的選取白底會在較晚重畫時把該列全90像素的195空白變成1。只在該完整底邊為全195或全1時允許，其他五列及selected列底邊須保持after。中文字原生16列的末列12字均空白，實際筆畫不落在該底邊。名字／其餘padding變更、未知後續同列輸出、未核顯示狀態或整列身分失效時撤除中文，下一幀保持原版英文碼；不能因碼帶碰巧相同而留舊中文。碼帶自身的rectMatches也須接受上述同一底邊例外，不能由舊全框判定先誤刪。
- 新家族入場時先撤除該y的舊家族事件，包含完整鍵不合格的情形；合成遇已撤除事件不得還原。原版新列尚未blit時按001保留pending規則，取消／關閉後原版畫格失配即移除。對整列身分的讀取不等於整列還原。
- 互動配置只支援本輪3倍，HD配置也須3倍才啟用新家族，避免GUI3／HD2共用已清除的低解析碼帶。目的x210、y保持原列，字形保持原生；Draw深複製字形後只消費owner已確認的事件。2倍及其他未核配置保持原版文字與缺譯紀錄，不改既有021或自動改倍率。
