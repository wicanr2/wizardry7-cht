# 006 — 流動文字（引擎折行成頁的段落）翻譯

狀態：DRAFT（第二版，回應第一輪審查：阻擋 3／應改 9／建議 6）
issue：#39（關聯 #22、#24）
證據：`docs/re/017`（F1–F13）；覆繪與還原機制沿用 spec 001

## 為什麼要做

迷宮開場旁白由引擎把同一段落的連續訊息行重新折行，再依列數分頁印出（F1–F6）。印字入口看到的是折行後的片段，
與訊息邊界對不上，整句原文查表不會命中。現況只有第 1 頁有中文，來自不在版控的 `story.txt` 逐列硬對應（F7）；
第 2 頁起全是英文，玩家看不懂旁白。訊息庫中屬於這種結構的段落有 2,906 個（F9），不能一頁一頁手工對應。

## 範圍

- 只處理呼叫點 `0110:bcfc`（迷宮開場旁白，F1）。新增呼叫點要先有 F13 那一組（字型、筆畫色、y 鏈、置中、返回位址）
  的量測證據，並各自登記列寬。
- 迷宮之前的故事文字走 `0110:be0c`（F12），仍由現行個別字串查表與 `story.txt` 處理，本規格不動它。
  它的比對規則另案（#40）。
- `bcfc` 的片段不再走個別字串查表：F7 的舊做法只對旁白第 1 頁有效，由本規格取代。
- 不改：一般字串查表、還原機制的判準（spec 001 R3）、F1 說明、自動地圖。

## 規格

### R1 資料：`workplace/bake/flow.json`

由 `tools/re/bake_flow.py` 從 `text/messages.json` 與 `text/story-trans.json` 產生（與 `xlate.json` 同樣是重建產物，不進版控）。

- **剝控制碼**：直接刪除 `<0x20` 的字元，不補空白。R2 的片段字串用同一個函式。
- **行**：剝控制碼後，去掉行首一個 `@`。下列行不列入索引，且截斷所在的段落：含 `& % ] ^ $ # ! "` 任一字元、
  含數字、含（行首之外的）`@`。訊息 id 2500–2574 一律不列入。剝完後沒有字詞的行（零字詞）不列入索引，也不截斷段落。
- **段落**：連續訊息 id（`id＝前一個列入的 id＋1`）的行組成一個段落；原文（剝控制碼後）行首是 `@` 的行開新段落。
- 每個段落記字詞序列（各行以單一空白相連後依空白切開）與每行的 `end`（該行最後一個字詞的位置＋1）。
- **每行譯文 `zh`**：取 `story-trans.json` 同 id 的譯文；非空、且每個字都能編成 Big5 雙位元組字、且能取得字形，才可用；
  否則 `zh` 為空（該行不可翻譯）。
- **字形表**：每個用到的字一份 15 列位圖，取自 `bake_font.glyph_scaled`（15 位元、靠右；與 `xlate.json` 同一函式），
  取字形失敗（`glyph_of` 拋 `ValueError`）視為 `zh` 空。不依賴 `xlate.json`，避免同鍵不同譯文互蓋（#24 盤點）。
- 缺檔：流動文字關閉，log 一行說明；片段仍照 R6 記錄，畫面保持英文。
- 建置輸出：段落數、可索引行數、譯文可用的行數、整段都可翻譯的段落數；另可加旗標 `--drop <id>` 產生缺一個段落的測試檔。

### R2 印字入口與頁的辨識

- 入口 hook 進入時**先**讀返回位址（`CS:[SP]`）：屬於流動文字呼叫點就走流動路徑，不查表；其他照舊。
- 流動路徑對每次印字取字串（剝控制碼），並做內容防呆：64 bytes 內須有 NUL、只含 0x20–0x7E、至少一個字詞；
  不合格視為本頁無效。字型 ID（`[SP+4]`）與進入時的 y0（`740C:0297`）一併記錄。
- **頁**：第一個片段須 `y0＝146`；之後每個片段須 `y0＝上一片段 y0＋12`，一頁至多 4 個片段。
  不符（y0 不是 146 起頭、y0 不連續、第 5 個片段）就結束目前頁並開新頁；新頁首片段 `y0≠146` 時新頁無效。
  無效的頁保持英文，log 一行。
- **片段閘門**（於返回後檢查，全部成立才算有效片段；F13）：字型 2、筆畫色 0x55（差異像素眾數）、離屏差異框中心 x 在 159–161。
  任一片段不符，整頁無效。
- 頁字詞序列＝該頁所有片段依序以空白切開再串接。
- 返回位址的認定沿用 spec 001 R2.2（SP＝進入 SP＋2）。片段沒有建立事件（無差異、無離屏、巢狀）時，頁無效。

### R3 頁的比對與譯文

每個有效片段印完後重算一次：

1. 候選：所有 `(段落, a)`，使 `段落.字詞[a : a+n]` 等於頁字詞序列（n＝頁字詞數）。
2. 完成的行：段落中 `a ≤ end−1 < a+n` 的行（一行在它最後一個字詞印出的那一頁顯示）。頁從一行中間開始時，
   那一行的最後一個字詞若落在本頁，也算本頁完成（F5：第 3 頁只顯示 15004 的尾巴，15004 的譯文在第 3 頁）。
3. 每個候選各得一個譯文（完成的行的 `zh` 依序相接）。沒有候選、沒有完成的行、或任一完成的行 `zh` 為空：本頁無譯文。
4. 多個候選：只有全部候選的譯文完全相同才採用；否則本頁無譯文，log 歧義（候選數、頁字詞）。

### R4 排版（每個繪製端各自計算）

`Draw` 與 `hdFrame` 的倍率可以不同（`-scale`、`-hd-scale`），且字形縮放不同：`Draw` 把字條放大 `hd＝max(1, scale÷2)` 倍，
`hdFrame` 逐像素 1:1。因此排版由各繪製端用自己的倍率 `k` 與字形放大 `hdf`（`Draw` 為 `hd`，`hdFrame` 為 1）計算，
不在快照節點算一次共用。

- 字距 `pitch＝17×hdf` 螢幕像素（15 px 字形＋2 px），列寬上限 184 遊戲像素（F5、F13 的英文最寬列 183）。
- 每列最多 `N＝floor(184×k ÷ pitch)` 字（至少 1）。
- **分詞**：`……`、`——` 各視為不可拆的一個單位，其餘每字一個單位。
- **換行**：依單位貪婪填滿到 `N` 字；再做避頭尾：下一列的第一個單位屬於 `，。、！？；：）」』》…—` 時，把目前列最後一個單位
  移到下一列（至多一次，列只剩一個單位時不移）；目前列最後一個單位屬於 `（「『《` 時，移到下一列。
- 最多 4 列；超過則本頁無譯文並 log。
- 每列水平置中於 x＝160：`X0＝160×k − n×pitch ÷ 2`（螢幕像素，整數除法）；`Y0＝(146＋12r)×k`（螢幕像素，r 從 0 起；不加 dy）。
- 依頁譯文、`k`、`hdf` 快取排版結果，頁譯文改變時才重算。

### R5 疊圖：兩趟判定

**事件**：每個有效片段建一個「還原事件」：框、前後像素、筆畫色與 spec 001 R2 相同，不帶字形，並記所屬頁。
頁記：片段數（已進入的有效片段）、事件清單、最後一個片段返回時的步數 `lastStep`、譯文、最後片段返回時的旁白文字帶快照
（x 68–251、y 146–194 的離屏色號；帶的範圍取 F2、F3 量到的英文範圍）。

`compose` 分兩趟：

1. **判定**：對所有事件依 spec 001 R3 表判定 `match`、`pending`、`dropped`，就地壓縮存活事件；不還原、不畫。
   非頁事件在此趟照舊處理（維持 spec 001 的行為）。
2. **裁決**：對每一頁，同時成立才「有效」：
   - 頁有譯文；
   - 事件數＝已進入的有效片段數；
   - 每個事件本趟都是 `match`；
   - 距 `lastStep` 至少 200,000 步（中間態不畫：一頁的各列間隔約 44,000 步，可能跨快照）；
   - **文字帶靜態檢查**：A000 在文字帶內、游標框之外，與 `lastStep` 時的離屏帶快照逐像素相等
     （中文列會畫到英文列以外，這條確認帶內沒有其他寫入；不成立就不畫並 log 一次 `流文 帶不符`）。

   有效頁：還原其事件的筆畫像素（同 spec 001 R4.1），並輸出頁的譯文供繪製端排版與畫中文；事件進 `shown`，
   `ov.shown` 計數在頁首次有效時加一。無效頁：其事件不還原、不進 `shown`，但仍依判定趟存活或被刪除，英文照舊顯示。

任何事件在判定趟被刪除，該頁自然無效。頁事件不需要重設 `shown` 旗標：`shown` 只表示「曾與 A000 相符」，用來決定被刪除或等待，
與頁是否有譯文無關。

### R6 可觀測性

- 每個流動文字片段 log 一行（任何模式，包括 `-flow ""`）：`流文 片段 步數 ret=<位址> font=<n> y0=<n> x0=<n> "<字串>"`。
  流動文字呼叫點的片段不再產生 `無譯文` 行；其他呼叫點的 `無譯文` 行加上 `ret=`。
- 每頁每次重算 log 一行：`流文 頁 步數 片段=<k> 字詞=<n> 候選=<c> 結果=<段落 id:a｜無譯文｜歧義｜超列｜無效>`。
- `-hd-at` 的 JSON 加 `Flow` 陣列（目前有效的頁）：`Fragments`（片段英文）、`Para`（段落首個訊息 id）、`A`、`N`、
  `Lines`（完成的行的訊息 id）、`Zh`（譯文字串）、`Scale`（該 JSON 的 `-hd-scale`）、`Rows`（每列 `X0`、`Y0` 螢幕像素與 `Text`）。
  還原事件照舊進 `Shown`（`G` 為空、`Before`／`After` 有值）；中文列不進 `Shown`。
- 新旗標 `-flow <路徑>`，預設 `workplace/bake/flow.json`；空字串停用。

## 驗收

工具：`tools/re/check_flow.py`（獨立於被測程式：只讀 `text/messages.json`、`text/story-trans.json`、en 模式 log 與 hdat 輸出，
依 R1–R4 用 Python 另寫一遍）。

1. **建置**：`bake_flow.py` 印出 段落 2,906、可索引行 6,307、譯文可用的行 4,915、整段都可翻譯的段落 2,167
   （R667 Python 原型，同一組規則；審查者獨立算過同一組規則的前身，數字以 `check_flow.py` 另算為準）。
2. **路線與步數**（wiz7 en 模式為準，三輪）：
   1. 探測：`-autoplay -autoplay-stop 1435000000 -flow ""`，`-clicks-at` 自 1440M 起每 10M 點 (160,170) 至 1540M；
      log 的 `流文 片段` 行依 R2 分頁，得每頁最後片段步數。
   2. en：同上，加 `-hd-at`＝各頁最後片段步數＋2,000,000（`-flow ""`）。
   3. zh：同上，`-hd-at` 步數相同（預設 flow）。
   `docs/re/017` 的片段數（4、4、1、4、4、3）與步數來自 `ovlprobe`；wiz7 走 `-clicks-at` 的實際步數以第 1 步的輸出為準，
   若頁數或片段數不同，先查原因再往下。
3. **A/B**：en 與 zh 在每個 `-hd-at` 步數的原版記憶體、A000、調色盤雜湊全部相同。
4. **覆蓋**：en log 分頁得 6 頁（片段數 4、4、1、4、4、3）；zh 的每一頁在對應的 `-hd-at` 都有 `Flow` 項。
5. **譯文**：`check_flow.py` 對每一頁算出期望 `Zh`，與 JSON 的 `Zh` 逐字相等；`Rows` 的 `Text` 相接後等於 `Zh`。
6. **排版**：`Rows` 列數 ≤ 4；每列字數 ≤ N；`Y0＝(146＋12r)×Scale`；列的水平中心與 `160×Scale` 相差不超過 `pitch`；
   避頭尾規則（檢查每列首字、末字）。`check_flow.py` 依 R4 另算一遍列文字，與 `Rows` 逐列相等。
7. **像素**：讀 hdat PNG，對每個 `Rows` 依 `bake_font.glyph_scaled`（字形資料）在 `X0＋i×17`、`Y0` 展開，該處像素等於頁筆畫色的 RGB；
   `Draw` 端另以 Xvfb `-draw-at` 取一頁（`-scale 3`）目視。
8. **英文不殘留**：對每個 `Flow` 頁的還原事件，比照 `check_overlay.py` 驗收 3：筆畫像素合成後等於還原色，違反數為 0。
   中英合成的差異只落在文字帶內（x 68–251、y 146–194）。
9. **負向**：以 `bake_flow.py --drop 15005` 產生缺第 4 頁段落的 flow.json，跑 zh：第 4 頁沒有 `Flow` 項、其合成帶內等於 A000；
   其餘頁不受影響。
10. **換頁過渡**：在第 4 頁第一個片段返回之後、200,000 步之內取 `-hd-at`：`Flow` 為空（新頁中間態不畫）；且第 3 頁的中文列已消失。
11. **倍率**：`-hd-scale 2` 再跑一輪（AGENTS 第 6 節），驗收 5–8 通過。
12. **回歸**：`check_overlay.py`（spec 001／002）、`fe-help-check.sh`、`automap-check.sh` 失敗 0 項；
    文字帶靜態檢查的 log `流文 帶不符` 為 0。

## 未決

- 引擎折行寬度的算法（F5 只量到最大約 183 px）：R4 的 184 是經驗值。
- 其他流動文字呼叫點（NPC 對話、戰鬥文字）尚未走到；含 `& % ] ^ $ # ! "`、數字、行中 `@` 的訊息不在本規格範圍。
- 迷宮之前的故事（`be0c`）與 `story.txt` 依賴另案（#40）。
- 被排除的行所在的段落不參與比對，若某頁的文字恰與這些段落重複，比對唯一性可能失真。
- 譯文含半形字的行視為無譯文，整段中有一行如此，整頁保持英文。
- 歧義率：整頁比對的歧義未量化，實作後以全庫自我比對量測（每個段落的每一種分頁）。
- #24 遷到 TSV 後，訊息 id 的相鄰資訊要保留（R1 的段落靠它組成）。
- 倍率 4 以上時 `Draw`（`hd＝scale÷2`）與 `hdFrame`（1:1）的字形大小不同，R4 讓各端各自計算，但兩端畫面不逐像素相同。
