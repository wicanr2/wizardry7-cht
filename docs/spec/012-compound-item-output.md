# 012：已量角色物品頁的兩行完整名稱

狀態：DRAFT；2026-10-01；議題#22、#28；入口[R725](../goal/R725-compound-item-output.md)。
原版定位／雜湊見[021](../re/021-compound-item-output.md)。

## 為什麼要做

原版把完整名稱拆成兩次印字，現有表卻以整串英文保存；兩部件查不到整串中文，
SHIELD還可能誤套通用文案。只補三個已量組合，不改原版名稱、資料、輸入或規則。

## 擬定契約

- C1：只接受021的三組完整英文與第一y128／142／170。第一返回ba40、第二ba63，
  font0、x18、第二y+6、前景索引105；同DS與SPentry，第二指標等於第一指標加byte長度+1，
  第一返回到第二入口36步。字串ASCII、NUL終止且長度在已量範圍；
  `first/second`英文唯一命中正式物品表。idx／中文／來源ID不作執行期鍵。
- C2：第一行完成後保存待配對狀態及印字前背景；下一次印字入口必須是C1的第二行，
  否則捨棄；返回時各驗SP，第二完整返回後才建立整串事件。
  部件不先獨立覆繪，尤其SHIELD不得誤套一般訊息。缺行、交錯caller、結構不符保留原文並記錄。
- C3：完整英文查現行正式物品來源，沿007字形／缺字守門，不新增譯表。
  中文自第一行原座標×倍率畫出；兩字型×兩倍率全在41×11原版矩形內，
  不縮字、不延伸；超寬、缺字或未核倍率回原文並記錄。
- C4：合成時兩行改筆畫及背景仍須與A000相符。只還原兩次印字實際改過的筆畫，
  保留紋理與行間隙；只寫覆繪畫布，不寫原版記憶體、離屏或A000。
  原版重寫／清場同域後移除整串事件，不沿用前件共用緩衝或只驗半行。
- C5：一般文字、故事、旁白、F1與地圖不受影響。LONGSWORD服務24新位置背景仍未知，
  不納入本次實作；其他slash名稱／座標未量，不預先放行。

## 擬定驗收

同正常輸入，關閉與兩字型×兩倍率，360M／400M的原版Step／Mem／A000／Pal相同；
A000／色盤逐位元相同，差異只在三個批准域及既有覆繪域。
獨立原始字型、第一印字前背景及兩行改筆畫核對完整PNG、三個完整英文鍵與中文。
必測缺半行、SP不符、交錯caller、非相鄰指標、座標／色彩／文字不符、
域外改寫／單行清場與缺字回退；以原文可見作玩家結果證據。
代表故事／旁白及F1回歸，原版存讀檔不增加欄位。

## 草稿缺口

待獨立審查實際欄位、背景保存／合成順序、部件抑制與清場契約。
READY前只做隔離研究，不接正式路徑；未量物品與另一bitmap路徑保持阻擋。
