## 契約

1. 只改story-trans.json的1007及1415之zh為「匯入巫術六」，en、ID與其餘欄位保持。這保留原譯文的匯入意義，避開ASCII略過，不改烘製格式或一般ASCII規則。
2. 只有shown清單同時包含上表六個英文鍵與精確座標時，才視為已量主選單。只調整上表事件，dy必須0，字形為一致的15或16列，且整串字格寬能放在本按鈕。其他情境、鍵、座標、尺寸、偏移及倍率沿既有位置，不猜新按鈕。
3. 只批准2×／3×，保留文字x起點與原生尺寸。字形倍率均為1；HD與Draw使用同一個純顯示位置計算。文字y改為 `(y0-2)*倍率 + (9*倍率-字高+1)/2` 的整數值，置於按鈕內。3×兩後端y與舊值相同；2×倚天上移2像素、Unifont上移3像素。
4. 不改事件生命週期、英文筆畫還原、原版按鈕、hit rect、資料、語意比較、滑鼠與存檔。事件與源字形不修改，只在HD或Draw畫筆的目的y採調整值。沒有完整主選單訊號時沿舊計算，不套到同字串的其他畫面。

## 驗收

- 獨立核catalog只變兩個zh，兩後端一般資源只變IMPORT (BANE)的正規化鍵；flow與help亦作差異核對，有其他變化即調查，不靜默接受。
- 從乾淨現行來源重建兩後端與正式binary。正常無輸入冷啟動272M，以倚天／Unifont各2×／3×及英文2×／3×取HD與真Draw。比較Step、Mem、A000、Pal、Mouse及.a000/.pal。全部正常WMclose退出，完整解析及有界清理沿R915契約。
- 各六個標籤的完整字格與實際筆畫都在上表按鈕內。獨立解析固定Unifont HEX及倚天stdfont.15原始字模，不以被測資源或位置helper產生預期值。匯入按鈕必須完整五字；既有五個標籤文案保持。
- 同字形資源修前／修後差異只能在批准的六個文字區域；3×位置保持，2×為明示預期變更。原版indexed、palette及記憶體摘要不變。
- 適當的Go測試核接線及非主選單、部分標籤、同英文不同座標的排除；正常GUI與獨立畫格驗證不可由fixture代替。未量到的排除分支不升CONFORMED。

只驗主選單標籤，不操作設定、匯入或防拷；圖片按鈕、其他畫面與十一組等交付閘門另依025及現行狀態表追蹤。
