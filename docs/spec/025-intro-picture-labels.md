## 為什麼要做

圖片內的`presents`沒有走印字入口，現有文字覆繪不能翻譯它。使用者要求圖片字樣也中文化，並於2026-10-04選定甲的六張原型：字帶內用周邊色階及紋理近似補底，再畫「呈獻」，保留品牌與原生字模，不採平滑色帶。當時本機對照為workplace/r943/intro-picture-comparison-v2.html；R977確認此檔未留存，不把失效連結當現行驗收入口。

補底是使用者選定的新繪近似，不是原版無字底圖。定版原型、原版indexed／palette及字型只存本機，不因技能要求保存草稿而把未獲散布權的素材加入Git。以原型來源、圖檔與報告雜湊固定外觀；資料來源索引及重跑入口回填研究025。這項決定不改遊戲規則、輸入、時基、原版素材、存檔或已定案的兩套字型。

## 契約

### R1：譯文與衍生字模

正式文案只取`text/intro-picture.zh-TW.tsv`，表頭沿既有獨立家族`en／zh／context／dy／source`。唯一鍵為`presents`，context為`intro.mon60.presents`、dy為0，source為`runtime:0110:5a9d`。譯文為已選定的「呈獻」。訊息ID不當比對鍵，也不新增到一般正規化查表。

烘製入口沿既有`tools/re/bake_profile_sex.py`的字型及編碼契約，另產生`intro-picture.json`於xlate資料旁。其結構沿既有獨立家族：schema=1、size=15或16、context、source、source_sha256及一筆entries，內含en、zh、dy=0、兩個g。UTF-8、五欄、唯一鍵、情境、控制碼、SHA、完整原生字模與缺字必須驗證。衍生JSON不是譯文正式來源，缺字中止烘製，禁止覆寫既有輸出。

執行期有界讀取、拒絕多份JSON及未知欄位，驗一鍵、兩字、兩套字高與有效位元；每字不得為空。一般字模高度必須一致且與本家族相同。英文模式、缺檔、非法資料或不符後端時保留整個原圖，記錄缺譯；不能只畫其中一字。

### R2：來源與完整轉送見證

在現有adapter的3921入口，只接受CS=0110、返回5B9B或5AFD、完整矩形參數0／0／319／199，保存本次SP及返回定位。返回由既有`arm` dispatcher通知；要求返回定位相同且SP＝進入SP＋2，不另外覆寫同一定位的文字hook。兩個返回都只通知完整轉送；5AFD同時服務MON60與MON61，不能用返回值當圖片家族。匹配返回時保存完成畫格indexed SHA-256。入口或下一檔載入不能替代完整轉送。

待返回槽至多一份。重入、返回不符或參數不符不建立新見證並記錄；原版照常執行。快照必須同時符合最近匹配完整轉送的indexed簽名、64000色號、模式13h、本規格六個整幀SHA及固定palette SHA，才產生覆繪view。完整indexed簽名區分同呼叫位置的不同畫面，不能僅憑位址或步數畫字。下一個匹配完整轉送更新完成簽名；未知完整幀不能產生中文，部分轉送亦不能沿用舊view。

固定palette SHA-256為`d689ae136905afa64a9329ddd123426f7e0f3cde6108c034e0249dbab0a9727c`。未量色盤與部分轉送保留原圖並記錄限定缺譯，不猜淡入或部分圖片構圖。沒有文字的前兩張及後續圖不算缺譯。

### R4：選定的近似補底

這是覆繪契約，不是對原版driver或底圖的推論。以本機`prototype_captions_v6.py`及其十二張圖作已選外觀基準。

1. 只讀當前原版indexed與palette。取字帶包圍盒四周各延伸4個像素，含最右／最下端外側4格；只取字帶外像素，且RGB符合R>G>B及R−B≥30。按x及y的奇偶分成四組，每組至少30樣本。其餘色階不用作紙頁樣本。
2. 對各組各RGB通道，以v=(1,x−200,y−110)，按y再x累加最小平方法的3×3矩陣與右側向量；以部分選主元的高斯消去求三個係數。奇異、非有限或樣本不足時整個view退回原圖，記錄，不產生部分補底。
3. 字帶內每個像素選同奇偶組最近樣本，距離平方相同依樣本y再x取最小。新RGB＝原樣本RGB＋擬合係數點乘目標v與樣本v的差，再四捨六入五成雙並限制0..255。近鄰紋理與色階均取原版快照副本，不讀或改圖片資產。
4. 輸出只含字帶內新RGB與當前palette[0]的字色。不得寫回indexed、palette、離屏緩衝、A000、原版記憶體或檔案。低解析合成副本的RGB可補底，原版indexed與既有comp收據保持。

### R5：原生中文字模與共同渲染

僅2倍及3倍支援本家族；其他倍率保留原圖並記錄。字模是後端原生15×15或16×16，字距2，不旋轉、不重採樣、不縮字。畫布仍整數放大。字格總寬為2×size＋2。

中心取四頂點x／y算術平均×畫布倍率，以四捨六入五成雙取整。x起點＝中心x−總寬÷2，y起點＝中心y−size÷2，除法取整。16字高時必須逐像素相同於甲原型；15字高只依已定案的原生字模與相同中心規則置中。兩倍率逐字格及筆畫核對安全範圍，不能裁字。

快照owner在既有evMu內建完整獨立view，補底RGB、原生字模及字色同一份發布。shared短鎖同時發布底圖與view；Draw只消費副本，不讀Oracle或猜步數。HD與Draw共用補底、中心、字距、字色與字模契約。畫布倍率或尺寸不符的格子不畫；unknown快照必須發布nil，不沿用舊中文。

### R6：撤除與缺譯

每次快照重新核對來源見證、原版整幀indexed與palette。改圖、未知簽名、palette不符或資料不可用時，本次不補底也不畫中文。不得用上一張patch遮住新圖。最後MON60字樣在MON61只載入、尚未上屏時保持；完整翻頁後撤除。

統計限定辨識、上屏、撤除與缺譯原因，不輸出原版訊息或答案。重複同狀態不灌大量記錄。此家族缺譯0只限正式實際觸發且合格的六張；未量過渡保留未量狀態。
