1. 在既有NUL入口／返回仲裁內增接此家族，不加第二個同址hook。原版字串最多64 bytes且不跨16-bit offset，必須有NUL。只有上表的caller、font、英文與x/y組合及可用catalog才由新家族處理；不符者沿原本一般路徑，不吞掉其他NPC原有中文。
2. e3a6的首行建立當前段落，後續行依上表順序取得。每行保留這次原版印字的不可變before／after、墨點差異框及原色。未知行、跳行或混入其他段落不能拼成完整中文。
3. 5f1e只更新當前已見行，不累加字詞、不開新段落。重畫須與來源行的文字、參數、差異框及原色before／after一致。無新差異時，只能在當前離屏框逐像素等於已留來源after時，重建同一行的覆繪事件；不寬放像素比例，不修改原始before／after。未匹配或空白沿一般路徑，空白不新增行或清cache。非空未知的這兩caller、font2且落三個NPC原點行與文字窗時，當前未完成組裝失效，不能與後續已知行拼接；已發布舊頁仍由原像素裁決，不提前抹除。
4. 頁內每行只有一個還原事件。替換重畫行時撤去舊事件，保留該段已實際取得的字詞。舊頁可在原版仍顯示原英文時維持；原版像素更新後必須撤除，不能把上一段中文殘留到新畫面。
5. 正文返回只建立pending。所有行實際取得、可見字詞精確等於一個完整英文來源鍵、譯文與字模完整後，仍須等待原版A000的每行after精確相符，沿既有游標框排除。NPC不使用006的部分墨點比例接受規則。整帶非墨點背景須與最後一次原版離屏快照相符，且沿既有flowQuiet200000步等待；計時起點由新e3a6內容更新，完全相同的cache不重置內容等待，避免原英文持續有效時退回英文。條件不齊即保留原文。
6. 英文只還原before≠after的實際墨點，保留紋理。中文原生15／16字形、2／3倍畫布及置中重排沿006／007，最多4列，原色沿當前色盤的85號。缺來源、歧義、未知樣式、缺字、超列、重畫背景不符或未完整發布，記有限原因並保留原版。
