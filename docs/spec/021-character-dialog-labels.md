# 021 新增角色對話框的小按鈕排版

狀態：READY。2026-10-04；[#22](https://github.com/wicanr2/wizardry7-cht/issues/22)、[#28](https://github.com/wicanr2/wizardry7-cht/issues/28)。R926獨立唯讀計畫審查0／0／0，主代理完整回讀後採用。

## 問題與證據

使用者要求所有按鈕完整中文化，中文必須留在按鈕內、保持原字形。[025的R921](../re/025-ui-localization-coverage.md#r921-新增角色對話框)已由正常GUI及固定步數中英12對量到：確定原版邊界63,166,73,9，文字起點94,168；取消63,182,73,9，文字82,184。2×的原生15／16列字格各超出1／2像素，Unifont筆畫共23個在框外；3×原位置可容納。來源是既有文字覆繪，不增加原版攔截點。

## 限定修正

- 增加純顯示座標helper，由HD及正式Draw共同呼叫；既有020主選單修正先保留，沒有新識別或資料寫入。
- 只接受scale2／3、dy0、精確OK@94,168或CANCEL@82,184，且畫面同時有020六個主選單訊號、ADD CHARACTER@61,152與兩個對話按鈕。缺任何訊號沿原位置。新增角色標題與其餘文字不移。
- 目的字模須非空、每字高度一致且為15或16，字距沿既有height+2，整串寬度須在原版x63..136放大後範圍。不能縮字或截字來套入，無法容納沿原位置並保留已知缺口。
- 符合時目的y＝原版按鈕頂點×scale＋(9×scale-height+1)/2。倚天2×上移2像素、Unifont2×上移3像素；3×位置保持。事件x/y、字模、原版記憶體、indexed、palette、存檔、滑鼠位置及按鈕命中區不變。
- 不改譯文或字型產生器，不以此修正處理六列角色動態字串、箭頭操作或其他同名按鈕。

## 驗收

1. 以獨立硬編的兩個原版矩形與兩種字高測公式及適用邊界，包含畫面缺訊號、不同座標、dy、字高、混合字高、空字模、過寬與其他倍率的保守回退；原事件保持。跑cmd/wiz7既有測試。
2. 用同R921資源重建正式binary，只允許指定Go來源變更。正常GUI再走新增與取消返回，仍核實際左鍵、持久角色內容不變及正常WM_DELETE退出；不以clicks-at取代。
3. 固定R921輸入及三個停止點，四組中文兩字型／倍率取完整HD與實際Draw，與R921修前及英文原版Step／Mem／A000／Pal／Mouse、.a000/.pal相同。獨立字型32字模、已量原版矩形與全按鈕像素；2×實際筆畫及整個字格均在框內，3×畫格位置保持。差異只在批准舊／新字格聯集，其餘像素保持。
4. 主選單及標題不移，六列缺譯及86次未譯事件分類保持。正常GUI只涵蓋此取消路線；防禦分支沒有實跑則保持READY，不擴稱全部同名按鈕或完整中文化完成。
