# 007：本機／發行字型保留原生尺寸

狀態：READY；2026-10-01；議題 #25。唯讀獨立審查一輪，無剩餘阻擋；實作及下列正常路徑驗收已通過。防禦分支只有單元／隔離驗證，原版未觸發，不升CONFORMED。
證據：[研究018](../re/018-distributable-font.md)、[研究017](../re/017-flow-text-evidence.md)、spec001／003／006。

## 為什麼要做與範圍

使用者已定案字型雙軌：倚天只供本機，發行版採可散布點陣字型；不縮中文字、不為缺字改譯。
GNU Unifont 17.0.05 全部涵蓋目前譯文，但104字需要16列。提供明示的烘製後端，保留原生字形。
只調整字形與覆繪幾何；不新增原版呼叫點，不改來源、譯文、英文鍵、遊戲分頁、按鍵、原版記憶體或存檔。

## 契約

- R1：烘製以環境變數 `WIZ7_FONT=eten|unifont` 選後端，預設 `eten`。Unifont 的 `WIZ7_UNIFONT_HEX` 必須指向固定版壓縮 HEX；先核對研究018雜湊，失敗即中止。未知後端中止，不默默回倚天。
- R2：倚天輸出仍為15×15、原有位元與字距不變。Unifont 每字保留16列，16位寬字不裁切、不重採樣；8位寬字在16位字格居中。ASCII 數字槽沿用自製數字，在16位字格中置中，不取倚天數字或符號。
- R3：一般覆繪由字形列數取得正方形尺寸（現有前端已如此）。流動文字資料新增 `size`，只允許15或16，舊資料缺欄時採15；每字列數及有效位元須符合尺寸，資料不合法時關閉該流文資料並記錄。列距、最多四列與原有字詞／來源閘門均不變。
- R4：流文字距一律2個字形像素；字距、排版列寬、字條寬高、置中、HD及Draw共用同一個資料尺寸。水平起點維持 `160×倍率－字數×(尺寸＋2)×字形倍率÷2` 的整數規則。不能只改畫筆而保留15像素排版。
- R5：F1全形字維持後端原生尺寸，ASCII採該後端8位寬原生字形。倚天位圖右移一位的對齊規則只套在倚天；Unifont位元原樣。F1行距20不變。為容納原生字形並讓現有說明完整可讀，取代spec003 R5的「超出一頁高時截斷」：
  - 保留頁面順序、標題、原文內容、既有翻頁鍵、暫停與輸入隔離；僅依目前畫布分割顯示頁。
  - 每欄上界y64；每欄容量 `max(1,(畫布高－64－48)/20)`。邊距32；單欄可用寬為`畫布寬－64`，兩欄各為`畫布寬/2－64`。
  - 逐行以實際字寬＋2字距折行，末字後不計空白；保留所有字元及空行。先按單欄寬折行，若列數超過單欄容量才改用兩欄寬重排；再按兩欄容量拆成多頁。不得截字、縮字或用畫筆裁切作排版。
  - 延續頁沿用原標題；頁尾沿用TSV樣板，頁碼計入延續頁。快取鍵包含畫布寬高，倍率切換後重新排版。
  - 每行字格及實際筆畫不得越出欄界；標題與頁尾亦須檢查原生字型的安全範圍。現有標題和頁尾皆須在2×／3×完整容納；未來資料超出時拒絕該說明資料並記錄，不截斷。
- R6：字模子集取正式來源及F1文字，保存字元清單與來源雜湊；`font/`僅保存說明、字元清單、授權／版本入口。第三方字型與烘製二進位只留本機或正式封包，包內保留OFL及著作權資訊。缺字須列明並中止烘製，不產生可誤用的部分新檔；執行期缺字仍沿用英文回退。
- R7：來源→烘製資料→前端覆繪→正常操作鏈維持唯讀。字型不能進入原版比較、查找、輸入、檔名或存檔；存檔內容仍由原版與dosgolem既有機制處理。

## 驗收與界線

1. 固定HEX全譯文＋F1子集缺字0；包含F1 ASCII、頁尾數字與自製數字槽。獨立解析確認位圖逐字完整，不只檢查字元存在；研究018的2,877字僅為非ASCII前置探針。
2. 倚天重建與`r674`的既有烘製／31故事頁／6旁白頁兩倍率逐位元相同（新增尺寸欄可忽略）。既有Go測試通過。F1修正裁切屬明示預期差異，不要求其PNG相同；要求來源字元全保留、每頁欄界與完整筆畫驗收。
3. Unifont由dosgolem重生故事31頁與旁白6頁兩倍率；全部同狀態樣本（含淡入、過渡、英文回退）中英原版Mem／A000／Pal／Step一致。穩定樣本中文譯文不變、無缺字英文回退，批准文字帶之外像素不變，完整HEX筆畫及18像素字距獨立核對；原有淡入／過渡閘門不變。
4. 一般覆繪抽測選單與防拷說明（不輸出答案），F1及故事Draw正常視窗檢查；Unifont字形不得被15列高度或15位寬裁掉。
5. 非法後端、錯誤雜湊、缺字、尺寸／字形不符以隔離負向測試驗證，不能修改正式字型或原版資料。
6. 容器清理與輸出1000:1000確認。此規格不等於全文路徑、完整通關或跨平台封包已完成；未被正常原版路徑觸發的防禦分支保持READY，另列未量到。
