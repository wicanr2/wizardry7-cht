# 012 — MSG.DBS 格式分析（#19，進行中）

日期：2026-09-21。issue #19。

## 已確認

- MSG.DBS 262,144 bytes（=2^18 整）、開頭非明文、全檔高熵
  （每 32KB 區段 248-252 種位元組值）→ 全程壓縮或加密，非只壓縮部分。
- 位元組分布偏斜（f7/de/bb/ef/b7/df/bd/6f/9b/37 為前十大，
  合計 ~29K/262K ≈ 11%）→ 非單純加密（加密會近均勻），**較像壓縮**。
- LZSS 標準 9-週期旗標對齊掃描：無訊號（9 個起點的 ≤2-bit 旗標密度
  149-173/1000，與隨機 145 相當）→ 非標準 LZSS 旗標格式，
  或旗標/對齊參數不同。
- 2-gram 統計：`04 02`×1015、`01 00`×833、`02 f7`×791——
  `04 02` 高頻，可能是長度/標記碼對。

## 已解出的部分（confirmed）

  LOAD SAVEGAME\0\0 CONFIGURATION\0\0 IMPORT (BANE)\0\0 QUIT GAME\0\0`
  ——字串以 NUL 結尾、**字首有控制碼**（顏色/位置屬性，
  如 `\x06\x11.\x00`）。
- 選單六項全部核對成功 ✓。
- 訊息主體是**按需解壓**：menu.state 的 RAM 中沒有遊戲本文的英文明文
  （"You "/the /spell 等常見詞 0 命中）——進遊戲後顯示訊息時才解壓。
