## 驗收欄位

每筆記錄畫面與控制、文字輸出或圖片字樣的來源、原版定位及座標空間、辨識訊號、正式中文畫格、點擊與回復結果、同狀態收據、字形及邊界、證據等級與下一個缺口。

正式程式已完成、動態畫面未量到與可選美化分開記錄。無文字圖示沒有可翻譯字樣，但其說明與操作仍須核對。玩家自行輸入的名字與既有原版英文關鍵字規則保持，不把它們誤計為未譯按鈕。
