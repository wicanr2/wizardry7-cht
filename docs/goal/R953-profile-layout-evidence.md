# R953 低倍率人物欄位排版證據

2026-10-04；沿[#22](https://github.com/wicanr2/wizardry7-cht/issues/22)、[#28](https://github.com/wicanr2/wizardry7-cht/issues/28)與[介面證據025](../re/025-ui-localization-coverage.md#r952-人物頁圖片操作與2倍行距)。前輪正常GUI與Unifont交疊定位已審查、推送並回讀，屬有效進度。完整中文化及可玩封包目標保持。

原生中文字高15／16，2倍原版行距只有12。先以既有正常選人輸入及唯讀探針量八屬性與等級／經驗／擊殺的數值輸出，確認呼叫位置、座標、字型、返回與離屏差異，才能在可撤回排版原型中保持文字與數值對齊。只在已量人物性別M／F返回訊號後、664M至784M之間，觀察resident0110:3895、返回0110:032a、屬性x139／145與八個已量y，另三個已量數值位置126,18與306,12／18，目的字串最多8 bytes，只接受1至3位十進位數字。生命／體力兩列只按已量HP入口至桌面首筆數值的呼叫順序取局部離屏差異，不讀數值或單字正文。前輪日誌為定位來源；不讀MSG、鄰文、答案表或任意字串。

SDK、正式程式、原版、字型與R937／R952舊收據唯讀；只寫workplace/r953及本輪文件。原版不修改，Scratch為新獨立目錄，固定輔助輸入明示不代替真正GUI。所有工作離線、有界、非root Docker，容器前綴wiz7-r953-；不得commit原版、字型、圖片或完整payload。規格未READY不寫正式實作，重大版面取捨先依grilling做原型；普通定位、測量與低風險排版修正不重新詢問已定案字型或預設倍率。

探針與原型結果由獨立唯讀審查後才回填現況，驗證通過後逐檔提交／推送與更新議題。此輪不重跑已充分的錄放故障、片頭呈獻或兩點圖片返回觀察。

結果：男女各13筆唯讀事件，14對原版停止點摘要及indexed／palette保持。雙字型原生15／16、四份重排及四份現行對照共八張PNG，獨立2,048,000像素相符；四張重排圖各31欄位交疊0、墨點交集0，四張現行圖保留既有交疊。原版248檔、38份cmd Go來源及四個Scratch的PCFILE.DBS保持。詳見[研究025](../re/025-ui-localization-coverage.md#r953-兩倍人物欄位原型)。正式程式未改，024既有READY範圍保持；排版候選未定版，完整2倍覆蓋未完成。兩次V1探針計數失敗及一次驗收器欄位讀法錯誤保留，未當產品缺陷。
