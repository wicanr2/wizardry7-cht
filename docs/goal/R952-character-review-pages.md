# R952 人物畫面與兩倍率缺口

2026-10-04；沿[#22](https://github.com/wicanr2/wizardry7-cht/issues/22)、[#28](https://github.com/wicanr2/wizardry7-cht/issues/28)、[024](../spec/024-character-review-output.md)及[介面證據025](../re/025-ui-localization-coverage.md)。前輪錄放契約已推送，採認問題未回覆；本輪推進獨立的完整中文介面驗收。

先核正式人物畫面的兩倍率限制，保持原生字型及原版資料。2倍性別欄只有12像素而字模為15／16，不能用縮字或猜補底圖繞過。以實際正常畫面核周邊可用區及其他人物分頁；需要改佈局時先留可丟棄原型，不在未READY規格下改正式程式。

正常GUI先由主選單檢視既有角色，再依看過的畫格進人物分頁及返回。每次新輸入前先檢視上一畫格，不用座標猜下一頁，不修改原版記憶體、角色或存檔。需要時只用既有固定輔助驗原版摘要及渲染，明示它不代替正常GUI。觀察訊息與圖片按鈕覆蓋，未到達者保留條件，不宣稱全遊戲完成。

只寫workplace/r952及本輪文件；正式程式、SDK、原版與舊收據唯讀。原版與字型掛唯讀，Scratch及新輸出為非root專用目錄；離線、有界Docker及單一可清理的GUI擁有程序。不得讀、推導或輸出手冊防拷答案；不得提交原版、字型、圖片或錄放payload。驗收或規格回填獨立唯讀審查後才逐檔提交及推送，議題進度回讀。

本輪取得11個真正Draw停止畫格、10次逐圖確認點擊。兩次人物頁點紅劍／蠟燭都回角色選單，沒有新的分頁，最終返回主選單、正常退出0。獨立檢查核原版248檔及現行來源保持；各畫格擷取後讀到的Scratch內容與原版相同，未冒稱PNG固定Step的檔案快照。另查R937已驗2倍Unifont人物頁，八屬性16像素字高配12像素行距，七對字格各交疊4列、實際筆畫交集58像素；本輪Unifont3倍相同八列皆0。這是新增排版缺陷的定位，未實作2倍修正，未把未量分頁或全遊戲列完成。完整範圍與重跑入口見[研究025](../re/025-ui-localization-coverage.md#r952-人物頁圖片操作與2倍行距)。
