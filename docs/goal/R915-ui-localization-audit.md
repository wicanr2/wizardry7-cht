## 目標與範圍

使用者要求再次檢查按鈕與訊息，包含圖片內的英文按鈕。以目前正式來源與可重播正常畫面建立覆蓋清單，逐項區分文字輸出、圖片字樣、無文字圖示、玩家自訂內容及既有規則保留的英文輸入。

- 先核正式前端、adapter、字型資源與現行驗收入口；譯文表、靜態字型、舊展示圖及原版英文收據不能單獨證明按鈕已中文化。
- 各畫面列出按鈕／訊息、來源路徑、辨識訊號、中文覆繪、字形邊界、點擊範圍及正常操作收據。圖片字樣也須追到實際繪製來源，不只搜尋文字 catalog。
- 沿已READY／CONFORMED的既有工具驗收已量路線，核正式中文畫面與原版同狀態；缺少正常路線或訊號時標未量到，保留具體缺口，不猜座標或修改原版。
- 新缺口依原版證據、DRAFT、獨立審查、READY、實作及同狀態驗證接續。不縮中文字，不將中文寫入原版記憶體、比較、檔名或存檔。
- 不進設定頁、不推導手冊答案，不新增未授權正文讀取、作弊、seed重擲或新state匯出。原版與完整原文畫格留本機；沒有可散布素材權即不加入公開圖集。
- 在Docker完成來源核對、畫格擷取與檢查；結果經獨立唯讀審查後推送、回填議題並精確回讀。十一組、TSV、錄放／音訊、存讀檔及封包閘門保持。

入口：[目前狀態](../../CONTEXT.md)、[介面覆蓋證據](../re/025-ui-localization-coverage.md)、[覆繪規格](../spec/001-overlay-no-write.md)。
已命中驗收、GUI及文件職責路由，載入reverse-engineer-retro-game-remake技能、GUI方法與verification reference；原版對拍仍以dosgolem為主，來源方法中的DOSBox或route patch不取代本專案規則。
