# R869：單檔錄放的完整設定解析

2026-10-03；工作 [#17](https://github.com/wicanr2/wizardry7-cht/issues/17)。

## 目標

在私人候選接合R862完整設定與既有逐列錄放格式，解除B1缺少完整設定wire解析的技術缺口。
依使用者已定案的單檔形式製作候選，不另設設定附檔，不採用尚未決定的停止或故障策略。

## 驗收

- 自製配置在同一檔頭內完整寫出、解析，並核對固定Go欄序的配置SHA。
- 必要欄位、巢狀物件與陣列元素拒絕未知、重複、大小寫別名、缺省、null、錯型別及非法Unicode。
- 損毀案例重新計算全檔內容SHA，避免只因外層校驗失敗而誤認解析守門有效。
- 保持既有命令順序與容量；檔頭容量包含完整設定及檔頭包裝。
- 外部預期配置不相符時拒絕回傳可供後續投遞的文件，原型本身沒有遊戲輸入API。
- 競爭檢查及獨立唯讀審查；原版、正式前端與SDK保持。

## 停止線

候選只在workplace/r869，013仍DRAFT。沒有實際LoadWith、原版Run、GUI、音訊裝置或三次重播。
解析自述配置不證明實際啟動相符，仍須R864擁有者綁定及正式整合。
候選schema不當正式相容承諾；B3故障保存及B4停止操作仍待既有共同決策。
