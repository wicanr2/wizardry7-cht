# R967 正式輸入錄放接線

2026-10-05；沿[#17](https://github.com/wicanr2/wizardry7-cht/issues/17)與[013 READY正式契約](../spec/013-input-recording.md#r951-production-contract)。產品取捨已全部定案，實作依既有契約，不重問相容、檔案形式、頁尾位置、停止續玩或故障保存。

1. 核對目前正式前端、SDK啟動資格API與R948至R950充分原型。載入規格閘門、顯示語意隔離、文件職責及必要SDK入口，只補接線所需事實，不重跑充分原型。
2. 接入單檔wiz7-input/1、完整有效設定及同次六資源，限Step0／Ticks0冷啟動與相同實際版本／平台／資料／初始存檔。錄放檔在Root／Scratch之外，避免改DOS可見集合；不內嵌原版bytes或公開操作payload。
3. 遊戲區外40px常駐頁尾與原生中文字模，玩家按鈕停止，完成當前操作及檔案收尾後繼續遊戲；後續操作不再錄製。故障保留無成功結尾的片段。原版輸入、存檔及正常聲音依既有契約保持。
4. 獨立唯讀來源審查，完整前端回歸及有意義的解析、資格、Writer故障與交錯案例。實作遇契約缺口回013，不猜測新行為。
5. 正常GUI從啟動錄製、按鈕停止與續玩，三次乾淨相符初始資料重播，獨立原版狀態及發布畫面核對；拒絕舊原型、錯版本／設定／資料、未完成片段及取消重播成功冒充。音訊與收尾依013分列驗收，不以軟體事件冒稱人耳或跨平台實機。
6. 結果獨立審查、收據封存、逐檔提交、推送及特定議題回讀。證據及未完成範圍寫CONTEXT／WORKLOG及既有研究022，完整中文化與可玩封包保持獨立門檻。

研究輸出只workplace/r967；原版、原字型及既有收據唯讀。所有工作負載沿既有離線、有界、UID/GID1000:1000 Docker；子代理明列可寫報告範圍，禁止commit／push、修改來源／SDK及讀出防拷答案。既有R966封存保持，未追蹤R433不動。
