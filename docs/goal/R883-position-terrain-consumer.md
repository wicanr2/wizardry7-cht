# R883：位置記錄的地形消費端

2026-10-03；工作[#36](https://github.com/wicanr2/wizardry7-cht/issues/36)。

## 目標

沿[R881證據](../re/016-party-position.md#r881-map-loader-route)，
從已證實的位置記錄與面向欄位反查移動及地形消費端，定位整張地圖的下一個必要資料來源。

- 使用既有IDA Pro9.4映像，原版與正式資料庫唯讀，只對新副本查詢。
- 先查resident及VMAZE的原生交叉參照、段設定與限定操作數；同數值位移只作候選，須核對基址。
- 每欄最多32個交叉參照，先取最多八個呼叫端的有界指令；有必要才沿具體資料流擴展。
- 不抽訊息、手冊或防拷答案，不掃描RAM，不執行原版，不注入呼叫、座標或記憶體。
- 不重試被拒的設定頁操作；該分支仍待明示授權。
- 只寫`workplace/r883/`及有索引的本輪證據與現況文件。正式SDK、覆繪、地圖、譯文及字型保持。
- 保留原名、EA、bytes、操作數與位址空間，推論等級分開列；靜態候選不當正常玩家驗收。
- 取得足以定位下一個資料消費端的證據即停止，不反編譯整個模組。整張地圖未READY前不進正式實作。
- 封存輸入與產物、獨立唯讀審查、擁有權及容器清理通過後提交、推送並回填#36。

結果入口：[研究016](../re/016-party-position.md)、[WORKLOG](../../WORKLOG.md)。
