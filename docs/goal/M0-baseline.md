# M0（輪 1）：探勘與基線

## 目標

之後每一期都要靠三樣東西：**讀得懂的執行檔**、**快速到達指定畫面的檢查點**、**可以比對的正確答案**。
M0 就是把這三樣建好，讓後面的實驗是秒級、有依據的。

巫術7比 psychic-war 多一個前置問題：**overlay 架構**（`DS.EXE` ＋ 11 個以上 `.OVR`）。
M0 要先把「overlay 怎麼載入、編譯器是誰」弄清楚，後面所有位址工作才有地基。

## 量測指標

- 從檢查點載入到可以下一步實驗的時間（目標：秒級）。
- dosgolem 與 DOSBox-X 在檢查點的**版面**不一致像素數（目標：0；顏色差異屬 M1）。
