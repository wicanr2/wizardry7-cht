# R868：正常停止錄製的操作比較

2026-10-03；既有工作 [#17](https://github.com/wicanr2/wizardry7-cht/issues/17)。

## 目標

製作不含原版資料的可丟棄操作原型，並列比較「預先指定停止步數」與「玩家按停止錄製」。
兩個候選均在下一安全邊界停止錄製並結束工作階段，避免把續玩行為混進同一問題。
候選只供比較，未經使用者選定不得進正式前端或013的READY契約。

## 驗收

- 原型離線可開啟，不載入遊戲、字型或網路資源。
- 真實瀏覽器測試兩候選的開始、正常停止、安全邊界及重設。
- 停止要求後不接受新的遊戲輸入；等待邊界期間可看見收尾狀態。
- 產出並目視核對比較圖，記錄工具、來源及輸出SHA。
- 正式cmd/wiz7、SDK、譯文與原版資料不變；013維持DRAFT。

## 邊界

原型只有自製計數器及示意畫面，沒有Writer、音訊、原版指令或可重播輸入。
不能當正式錄放、期限保證、原版對拍或完整可玩證據。
故障保存策略仍待既有問題的答案；本輪不以沉默代替同意，也不新增相依提問。
