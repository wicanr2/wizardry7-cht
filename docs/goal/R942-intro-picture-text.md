# R942 片頭圖片文字來源

2026-10-04；沿[#22](https://github.com/wicanr2/wizardry7-cht/issues/22)與[025覆蓋矩陣](../re/025-ui-localization-coverage.md#目前覆蓋矩陣)，定位正常冷啟動60M畫面中的PRESENTS字樣。先確認實際圖片素材、唯讀載入與blit路徑、畫面座標、出現及消失時機，再擬定中文覆繪契約。品牌字樣與其他未知圖片不由本項推定完成。

只用無玩家輸入的正常冷啟動，截止於既有路線已量的200M標題，核對圖片字樣消失。探針只記檔名、呼叫位置、座標、索引色盤與畫格，不讀訊息、鄰文、手冊防拷答案或詞庫正文，不改原版記憶體、時基、種子及存檔。原版、SDK及舊收據唯讀；私人新產物寫workplace/r942，原始素材不提交。

沿既有離線、非root、有界Docker工具鏈。觀察開／關在固定停止點比較完整原版狀態、indexed及palette，檢查來源雜湊、輸出擁有權與容器清理。證據由獨立唯讀審查後回填025；正式接線須另有READY規格及同狀態GUI驗收。本項不降低十一組、二倍欄位、錄放、冷存讀、音訊與封包交付門檻。
