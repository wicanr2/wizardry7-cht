# R877：整張地圖的資料讀取入口

2026-10-03；工作[#36](https://github.com/wicanr2/wizardry7-cht/issues/36)。

## 目標

沿已定案的自動／整張地圖功能，確認MAZEDATA.VGA的實際用途、讀取位置與資料邊界。
先查既有IDA資料庫及呼叫端；取得足以限定下一個地圖切片的證據後停止，不反編譯整個遊戲。

## 範圍與驗收

- 沿用[位置證據016](../re/016-party-position.md)及[自動地圖005](../spec/005-automap.md)，不重開兩格驗收。
- 原版與既有IDA資料庫唯讀，查詢只在新副本；分析全部使用既有離線Docker，明示UID及資源限制。
- 記錄輸入SHA、IDA版本、資料庫位址空間、原始名稱、位址、bytes與xref。語意標示證據等級，不改原始定位。
- 只追地圖資料的選取、讀取與玩家路徑所需的最小資料流；不讀手冊、防拷答案表或對話正文。
- 第一個輸出先證工具與資料庫身分，再核對實際讀取端，不由檔名或大小直接推論地圖格式。
- 未達READY不改正式地圖、資料格式、UI、存檔或錄放；原版未知與可選美化分開記錄。
- 來源及產物擁有權、唯讀輸入保持、容器清理與獨立唯讀證據審查通過後提交；#36保持OPEN直到全部功能驗收。

結果入口：[研究016](../re/016-party-position.md)、[WORKLOG](../../WORKLOG.md)。

- IDA直接解碼103條指令，原始OVR位元組及relative call獨立算式全部相符；20來源與29產物已封存。
