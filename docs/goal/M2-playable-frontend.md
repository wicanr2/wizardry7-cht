# M2（輪 4）：可遊玩前端

## 目標

前端從「能開」到「能玩」：用模擬試玩證明玩家可以從主選單一路操作進遊戲，
並把節拍、輸入、音訊補成 M2 的完成定義。

## 完成定義

| 項目 | 驗收 | issue |
|---|---|---|
| 模擬試玩 | 主選單 → 建隊伍（或等價操作）→ 進入遊戲第一個可操作畫面；全程截圖＋狀態檔；操作用點擊/鍵盤（真實輸入路徑） | #16 |
| 輸入錄放 | 試玩腳本可錄製並重播（重播後畫面雜湊與原跑一致） | #17 |
| 音訊 | 前端有聲音：先期以 OPL 事件流驅動合成或效果音路徑；至少「音樂播放中」可被量測 | #18 |
| 節拍 | -ips 之外支援 DOSBox 相容 cycles 對齊；速度切換不破壞決定性 | #16 |

## 量測指標

輸入錄放續行入口：[研究022](../re/022-input-recording-boundary.md)、[013正式契約](../spec/013-input-recording.md)。
音訊續行入口：[R701](R701-audio-playability.md)、[研究020](../re/020-player-audio.md)。

- 試玩：每個轉場的步數與到達時間；狀態檔恢復秒級。
- 音訊：合成輸出與事件流的對應（音符開關對齊事件時間戳）。
- 錄放：重播後畫面雜湊 100% 一致。

## 不在範圍內

- 中文繪製與翻譯（M3/M4）。
- OPL2 合成的音色保真度調校（先求「有聲音且對齊事件」）。
- 存讀檔UI的美化。
