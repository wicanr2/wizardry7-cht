# R857：剩餘十一組的定向迷宮觀察

日期：2026-10-03。工作來源：[#24](https://github.com/wicanr2/wizardry7-cht/issues/24)、[#22](https://github.com/wicanr2/wizardry7-cht/issues/22)。

## 目標

觀察直接對準剩餘十一組，沿R843原先位置尚未量到的面向1續行。從合法checkpoint重播固定前綴，逐次看原版畫格後才送下一個正常操作。

## 範圍與停止線

- 使用者於2026-10-03明示授權十一個精確英文鍵的29個既有出處。只在原版實際取用這些ID時，唯讀觀察最多64 bytes的目的緩衝；不讀鄰文或答案。
- 首次29來源建置被自動審查拒絕，未編譯或執行。等待期間僅建立原有10短句來源的副本，沒有原版執行；取得明示授權後才建置29來源探針。
- 來源ID只作研究白名單，不作正式轉譯鍵。
- 沿用先排除防拷來源、再取得指標的護欄。不擴讀任何鄰文、手冊、防拷答案或autoplay輸入。
- 私人探針讀取只接受白名單來源緩衝及完全相同英文，記錄取得／解碼／同指標印字鏈；沒有鏈時不猜字串出處。
- 完整重播R843的26停止點前綴，之後最多十二次正常操作，每次固定20M及原有Click內部6M。
- 兩個程序同步，觀察開／關初態及輸入相同；每步比較RAM、indexed、palette、暫存器及原始畫格。
- 新畫面出現戰鬥、對話或新的操作需求時先停下判讀；不盲點、不改存檔／座標／原版記憶體、不重擲挑結果。
- 原版、SDK及歷史收據唯讀；輸出留在workplace/r857，不匯出新state。

## 完成條件

新的路線或目標取得有可重播收據。未命中只限本路線，不改十一組交付門檻。有限研究及文件經唯讀獨立審查後推送、回讀Issue進度；自有容器、root-owned及誤建.md目錄為零。

暖非GUI收據不代替中文覆繪、完整冷可玩、存讀檔、音訊、錄放或封包驗收；017的十來源觀察保持既有證據，不由本輪更換白名單後的結果推論。
