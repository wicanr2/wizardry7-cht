# R979 防拷題目附答案與正常遊玩起點

2026-10-08；整體目標仍為完成巫術7中文化。沿[#45](https://github.com/wicanr2/wizardry7-cht/issues/45)。使用者明示沒有暖進度備份，要求代理正常遊玩，
並新增「防拷答案直接貼在問題後面」。這項明示指示優先於先前不讀／不顯示答案的限制。

## 定案與邊界

- 在中文題目後附原版所需的英文答案，保留原版驗證、存檔、遊戲規則與正常輸入。
- 允許僅讀目前題目及對應答案所需的資料；不讀鄰文或對話詞庫，答案與完整收據只留本機。
- 不公開或提交答案表，不因此處理#26移出版控，也不修改EXE、RAM判定或跳關。
- 代理可以沿正常鍵鼠與字元輸入遊玩，建立新的合法進度及保存／冷LOAD驗收來源。

## 工作

1. 正常原版冷啟動／建隊至防拷，窄觀察題目數值、原始資料ID及目的緩衝；原版只讀。
2. 確認答案定位規則與題目完整性，DRAFT規格寫來源／狀態、顯示矩形、字型、撤除、
   未知／缺資料回退及HD／Draw共同接線。未知不猜補，獨立READY審查後才正式實作。
3. 在目前題目後顯示答案，以實際字型驗完整筆畫與輸入區不重疊；不讓答案文字參與比較或序列化。
4. 正常GUI驗題目、附答案、原版輸入驗證及撤除；與關閉提示的同狀態原版RAM／indexed／palette比較。
5. 按正常遊玩建立持久進度，保存後移動、關窗、冷LOAD及隊員／位置還原依014逐項驗收。
   新收據供008情境及全文中文覆蓋接續使用，不以到迷宮冒稱全遊戲完成。
