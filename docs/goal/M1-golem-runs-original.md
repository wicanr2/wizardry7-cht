# M1（輪 2）：原版在 golem 上完整可跑

## 目標

M0 證明「開得起來」；M1 要回答「**跑得完整**」：

1. **不中途死掉**——遊戲在 golem 上自行退出的原因要查出並排除（假說：唯讀掛載
   讓寫檔失敗，`INSERT SAVEGAME DISK` 路徑）。
2. **走得更遠**——按鍵腳本推進到主選單與第一個可操作畫面，補齊 M0 沒做到的檢查點。
3. **顏色也對**——M0 只比了版面（遮罩差異 0）；M1 要 RGB 逐像素差異 0。
4. **聲音有據**——OPL2 埠寫入序列與 DOSBox-X 逐筆對拍（事件層，不是合成音色）。
5. **決定性**——同輸入兩次跑，狀態檔／畫面／記憶體逐位元組相同。

## 完成定義

| 項目 | 驗收 | issue |
|---|---|---|
| 可寫執行環境 | 唯讀掛載換可寫複本後，遊戲不再在標題後自行退出（或退出原因實錄並歸因） | #8 |
| 選單檢查點 | 穩定標題、主選單、第一個可操作畫面三個狀態檔＋恢復驗證；`docs/re/006` | #9 |
| 顏色對拍 | 穩定標題 RGB 逐像素差異 0（golem 色盤傾印 vs DOSBox-X）；`docs/re/006` | #10 |
| 決定性 | 同輸入兩次：狀態檔雜湊相同、畫面雜湊相同、記憶體 dump 相同 | #11 |
| OPL2 事件層 | golem 埠寫入紀錄 vs DOSBox-X `.dro`（DX-CAPTURE /O）逐筆比對，結果進 `docs/re/007` | #12 |

## 量測指標

- 穩定標題 RGB 差異像素數（目標 0；超過就列出差異色的 DAC entry）。
- OPL2 事件不一致筆數（目標 0；register/value/timestamp 三欄）。
- 決定性：兩次 run 的 SHA-256 完全相同。

## 不在範圍內

- OPL2 合成音色（波形保真度）——psychic-war 是 M2 之後才做到，本輪只對事件層。
- 文字攔截、翻譯（M3+）。
- overlay loader 的 `.tail` fixup 語意（M3 前置，另輪處理）。
- 音效卡偵測的完整矩陣（MT-32 路徑不在這輪；AdLib/OPL2 一條即可）。

## 起點

M0 產物：banner/title 檢查點與狀態檔（[005](005-dosboxx-parity.md)）、
DOSBox-X 24 張參照快照、開機時間軸兩邊逐步吻合。遊戲用 EMS（[003](../re/003-golem-boot.md)）、
模式 13h、PIT 分頻 2376、`-adlib` 要開。
