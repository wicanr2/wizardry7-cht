# R943 片頭呈獻字樣與中文排版

2026-10-04；沿[#22](https://github.com/wicanr2/wizardry7-cht/issues/22)及[025](../re/025-ui-localization-coverage.md#r942-片頭圖片來源與切換)，承接已量MON60圖片路線，核對六張含呈獻字樣的畫格。目標是中文出現在原圖片內，正常翻頁即移除，不動原版記憶體、時基或素材。

先由已封存indexed／palette逐張量文字及背景範圍，製作可丟棄原生中文字模覆繪，標示背景修補與原底圖證據差異。原版、SDK、字型及R942收據唯讀，私人產物只寫workplace/r943；不擴讀MSG、手冊、答案或未知圖片。定稿走DRAFT→獨立READY審查後才接正式前端，以兩字型、兩倍率的正常GUI與同狀態對照驗證。繼續遵守既有原生字型及畫布定案，不縮中文字。

可重跑來源與驗收回填025；CONTEXT保存現況，WORKLOG追加歷程。沿既有離線、非root、有界Docker，收尾核來源雜湊、輸出擁有權與容器清理。其餘圖片文字、十一組、錄放、存讀與封包門檻保持，不把本項局部結果當全遊戲完成。

本輪限定成果已完成：六張圖片正式覆繪、兩字型兩倍率正常GUI、32個中英文同狀態點及16個舊新英文控制通過。結果、原型來源與重跑入口統一保存在[研究025](../re/025-ui-localization-coverage.md#r943-正式呈獻覆繪驗收)，025維持READY。推送與議題更新另記WORKLOG。
