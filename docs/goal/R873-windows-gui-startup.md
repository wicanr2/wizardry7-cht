# R873：Windows 遊戲視窗與存檔路徑啟動

2026-10-03；工作 [#18](https://github.com/wicanr2/wizardry7-cht/issues/18)、[#42](https://github.com/wicanr2/wizardry7-cht/issues/42)。

## 目標

從目前正式來源重建Windows amd64前端，在既有Wine9容器啟動真正遊戲視窗。
驗證系統使用者資料目錄及明示save-dir能通過正式守門，原版素材唯讀。
補足R810只驗命令列的缺口，不重開已完成的Linux測試或更改玩家操作。

## 驗收

- 固定Go／模組離線重建，核對PE平台、來源前後雜湊與實際編譯清單。
- 真正視窗繪製原版冷啟動畫面，擷取並目視判讀。
- F1說明以X鍵盤事件開啟／關閉，中文可讀；關窗正常退出。
- 預設及明示存檔目錄分別核對實際路徑、目錄存在及無自然寫檔。
- 原版248檔SHA保持，測試沒有autoplay、答案、作弊或狀態注入。
- 環境失敗先分類並保留收據，不以不明的Wine差異修改原版或正式程式。
- 輸出擁有權、容器清理及有限證據審查完成後提交並更新議題。

## 停止線

本輪產物只在workplace/r873，不建立正式dist-all或發行版號。
Wine視窗不當Windows真機、音訊人耳、冷LOAD還原、正常遊玩或通關驗收。
先驗靜音視窗；音訊硬體與完整玩家路線仍列原門檻。
沿已確認的預設3倍畫布及虛擬時鐘，不採新graphics backend或節拍產品決策。

結果入口：[研究020](../re/020-player-audio.md)、[WORKLOG](../../WORKLOG.md)。

## 結果

兩條Wine9冷啟動路徑通過960×600真視窗、F1暫停／恢復及標準關窗退出0。
明示／系統預設目錄存在且自然寫檔0，原版248檔SHA保持；200k及60M的四項摘要相同。
80項來源、145項輸出封存，中文說明第一頁目視可讀。
只完成本輪限定驗證，Windows真機、音訊、冷LOAD與正式封包未驗；#18、#42保持OPEN。
